# Telco AEGIS — TM Forum Catalyst Project C26.0.980

Source: https://www.tmforum.org/catalysts/projects/C26.0.980/telco-aegis-autonomous-ecosystem-for-generative-intelligence-and-security

**What it is**: a 2026 TM Forum Catalyst (industry proof-of-concept) for an autonomous, multi-agentic AI security ecosystem for telecom networks — built on the Model Context Protocol (MCP), aligned to TM Forum's Open Digital Architecture (ODA) and Autonomous Networks Level 4. It runs a closed-loop DevSecOps lifecycle (monitor → detect → generate → validate → deploy) with specialized AI agents collaborating on threat response (e.g. UNC3886-style persistence, SS7 signaling attacks).

**Why it's relevant to the skripsi**: it's a real industry example of a governed, multi-agent LLM system making prioritized, autonomous security decisions in production-adjacent conditions — useful as a motivating case study / industry-relevance citation for the "Pengaplikasian Priority-Based Scheduling untuk Sistem LLM Multi-Agent dalam Konteks Sistem Keamanan Siber" introduction, even though it's a vendor Catalyst writeup rather than a peer-reviewed paper (cite carefully, as industry evidence not academic literature).
